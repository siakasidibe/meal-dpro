# Le MEAL en pratique

Cours gratuit en ligne sur le suivi, l'évaluation, la redevabilité et l'apprentissage (MEAL) des projets, proposé par le cabinet M.C Consulting Mopti.

- 8 modules (0 à 7) et une séance finale, 40 heures sur 9 samedis.
- Un cas fil rouge malien : le projet BADENYA (projet réel anonymisé, commune de Bangassi, cercle de Kayes).
- Site statique publié avec GitHub Pages, lisible sur téléphone et hors connexion.

Contenu original. Le guide MEAL DPro (PM4NGOs, licence CC BY-NC-SA 4.0) est cité comme référence ; ce cours n'est pas une certification MEAL DPro.
